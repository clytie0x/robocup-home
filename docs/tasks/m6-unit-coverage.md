# M6 unit coverage

Simulated pick, carry, drop, and handoff for one gripper. This note does not change a row in [3.1 Carry My Luggage](3.1-carry-my-luggage.md). Every acceptance `result` there stays `not-run`. A unit or harness result is not a scenario-simulation acceptance pass and not a hardware result.

`manipulation::decide` reads a scene and returns an action or a refusal. It does not change the scene and it does not confirm the trip. `sim_runtime` owns the only gripper and each bag's custody. `harness` admits the trip event before it changes the world. `Ok` from `Trip::apply` with no effect is the budget deadline: the wrapper stores `TimeUp` and does not pick, drop, signal, or hand the bag off. `PickEnd::Matched` is the only pick success, and only when the adapter holds that same bag.

`REACH_MM` is 2500 and `SITE` is `robot-base`. Both are assumptions. The professor PDF states no arm length, grasp pose, or drop point. The fixture robot stays at `(0, 0)`. Both seeded bags are inside that disk, so the base is not moved. A held bag and a dropped bag are recorded at the robot base. This model has no gripper frame. After handoff the bag is at the operator pose with operator custody. It is not deleted.

Ready is a separate `MockReady` call. A grasp does not set `ready`. Follow is not executed. Handoff tests that need `Phase::Releasing` apply `Event::Arrived` as a fixture. That event is not navigation and does not move the base. It is not an M7 pass. M7 and M8 are not this milestone.

The seven open scoring rows stay open: `CML-GEN-MAIN`, `CML-SHEET-START`, `CML-OPEN-PARTIAL`, `CML-OPEN-ABSENT`, `CML-OPEN-CAP`, `CML-OPEN-DROP`, `CML-OPEN-FOLLOW`. No score is chosen. A drop is recorded and is not priced.
