# Carry My Luggage acceptance specification

This file is the acceptance reference for the laptop simulation of one RoboCup@Home test.
The repository file name keeps the id 3.1. That id is not the section number in the baseline edition.

The baseline is the final RoboCup@Home rulebook release 2025.1, section 5.1, Help Me Carry.
The source label in that edition is `test:carry-my-luggage`.
A simulation that passes a `sim` row tests rule behavior only. It does not certify a physical robot, a live person, or a real public space.

No row has been executed. Every `result` is `not-run`. A `block` value of `open` means the row cannot pass until the conflict is decided. Do not treat an open row as a pass.

## How to read a row

`kind` is `official` for a clause in the baseline PDF, `derived` for a test oracle or a reading that the PDF does not state, and `assumption` for a simulation stand-in.
`result` stays `not-run` until a command named in [AGENTS.md](../../AGENTS.md) has been run.
`gate` is `sim` or `hardware`. `unspecified` is unused in this file because each row has a known layer.
`block` is `none` or `open`.

A `sim` row can later be tested with a modeled operator, a modeled bag, and a modeled space. A pass on that row does not close the matching `hardware` row.

The short rulebook sheet on printed page 41 is the score list. Penalties are printed and are not included in the total line. The scoresheet macro adds only positive `\scoreitem` values to that total ([macros_scoresheets.tex](https://github.com/RoboCupAtHome/RuleBook/blob/26403178bcdf39d2c5d9ed2e27849a9d8af1401e/setup/macros_scoresheets.tex) lines 358 to 372 and 504 to 522).

| Rediscovering the operator by direct contact | -200 | no |
| Not attending (see sec. 3.9.1) | -500 | no |
| Using alternative start signal (see sec. 3.7.8) | -100 | no |
| Outstanding performance (see sec. 3.9.3) | 111 | no |
| Total Score (excluding special penalties & standard bonuses) | 1115 | total |

The nine positive lines sum to 1115. The printed total is 1115.
300 + 15 + 100 + 50 + 50 + 50 + 50 + 200 + 300 = 1115.

Section 3.9.3 allows an outstanding-performance bonus of up to 10 percent of the maximum test score. The sheet computes that with integer arithmetic. It multiplies 1115 by 10 and then divides by 100, which truncates to 111. The exact tenth of 1115 is 111.5, and 111.5 is not printed. The Technical Committee decides whether any of that bonus is awarded. 111 is the printed cap, not an automatic award.

The commented `\setTotalScore{1000}` in the scoresheet source is not printed. 1000 is not the maximum.

The sheet prints "The maximum time for this test is 5:00 minutes." Section 3.7.14 states that a Stage I test is 5 minutes unless stated otherwise. Those two statements agree on 5 minutes.
