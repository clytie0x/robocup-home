A `sim` row can test rule behavior on a model. It does not certify a physical robot or a real public place. A `pass` names the episode test that asserts that row. The seven open scoring rows and the three hardware rows stay `not-run`. Source integrity is checked by `artifacts/check_m1_spec.py`, and that check is not a task score.

## How to read a row

`kind` is `official`, `derived`, or `assumption`.
`result` is `pass` or `fail` only when the test cell names an episode test that contains the row id. Open rows and hardware rows stay `not-run`.
`gate` is `sim` or `hardware`.
`block` `open` means a real scoring conflict. A behavioral pass cannot pass while it stays open.
A missing distance or count is an `assumption` row. A later simulation may choose a labeled value. That value is not a rule, and the missing number does not by itself block the rest of the scorer.

## Printed score rows
